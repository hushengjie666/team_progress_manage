## Main review path

1. Sign in using the supplied review account.
2. Use the workspace selector in the top bar to filter project and task data.
3. Open a project to review overview, schedule, task, member, and settings tabs.
4. Open My Tasks and select a task to view or edit its details.
5. Open Focus, select a task, and start the timer.
6. Lock the iPhone or open Dynamic Island to inspect the Live Activity.
7. Stop the timer before leaving the review account.
