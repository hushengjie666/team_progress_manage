## 此次发现和修复

1. 新建项目的服务器确认或远端刷新会重置正在编辑的项目设置。现在保留用户改过的字段，同时更新未编辑字段；切换项目会重新初始化。增加 4 项领域测试及一个延迟确认的浏览器测试，并在真实桌面流程中验证保存结果。
2. 客户端为新项目负责人生成的临时成员 ID 与后台创建的 ID 不一致。立即创建任务时可能引用仅存在于本地的成员。现在新项目的乐观状态采用后台相同的负责人 ID，测试验证创建确认前、确认后及另一客户端重新加载时的任务成员关联。
3. 真实桌面测试脚本遗漏客户端版本请求头、复用正式应用标识、未严格限制弹窗操作范围，并在按钮保存中仍不可用时点击。已补齐合同请求头、隔离应用和后端配置、限制操作容器并等待按钮可用。测试完成后清理自己的数据库及缓存，保留用户登录和应用数据。

新增真实数据库测试检查模板实例与集合编辑的持久化，计时暂停/继续/重置/完成的状态及番茄结算，以及跨工作区移动后的明细关联和任务删除清理。

## 执行方式

```sh
npm run verify:fast
npm run typecheck:test
npm run verify:quality
npm run verify:e2e
npm run plugin:test
cargo test --manifest-path src-tauri/Cargo.toml --lib
# 设置独立测试实例的 TM_BACKEND_TEST_MYSQL_DSN 后执行：
npm run verify:backend
npm run test:tauri:functional:real
```

真实 MySQL 测试必须配置独立测试实例，不能将生产 DSN 作为测试目标。完整桌面流程通过 `test:tauri:functional:real` 自动创建和清理测试库。

## 验证边界

浏览器 WebKit 视口测试与签名 iOS Archive/IPA 的构建校验不能代替真机验收。本次未验证 iPhone 真机后台通知、锁屏 Live Activity、系统权限弹窗及 App Store 审核。macOS 分发包采用本地 ad-hoc 签名；签名和安装完整性验证与 Apple 公证是不同检查。

本次没有新增数据库迁移，合同保持 release 0.2.11 / API 2 / schema 14。旧数据中已经缺失的原始内容不在本次功能修复范围内。
