# 专注宠物全交互与界面游戏化重设计

## 目标与使用场景
目前 `AD-010` 已落地悬浮专注宠物的核心经济与养成机制，但宠物互动界面仍偏“传统网页表单弹窗”（白底黑字卡片、原生 `<progress>` 条、5 个文字标签页、后台列表风的道具行），悬浮本体也缺少主动生命感与即时把玩反馈。

本次需求将与宠物相关的**全部交互与视觉体验整体重设计为连贯的桌宠小游戏体验**（温暖绘本 / 动物森友会清新质感 × QQ 宠物式随手互动）：让悬浮宠物真正“活起来”、在桌面即可逗宠与喂饭，并把宠物小屋升级为带实时互动舞台与游戏道具格的掌中游戏窗口；同时完全沿用现有经济数值与账号存档数据，不破坏既有玩法。

## 本次范围
1. **悬浮桌宠本体：活起来的 QQ 宠物式桌面伴侣**
   - **生命感微动作与底座**：为悬浮宠物增加柔和的地面微光/草坪阴影底座、更丰富的表情与动作细节（常规呼吸与偶发眨眼、专注时认真陪伴节奏、开心蹦跳、偏饿委屈、饥饿危急发抖），并伴随贴合状态的轻盈**游戏对话气泡**（短暂停留后自动淡出，绝不拦截操作）。
   - **桌面环绕式快捷动作轮盘**：
     - 已领养状态下，轻点悬浮宠物先在其周围弹出精致的**环绕式游戏圆形动作气泡**（包含「摸摸」「快捷喂食」「宠物小屋」等核心快捷动作）及极简迷你 HUD（饱食度能量条 + 金币胶囊），点空白处或按 `Esc` 自动收起。
     - **桌面摸头/逗宠**：点击「摸摸」立即触发宠物开心眯眼跳动、头顶冒出爱心/闪光微粒与俏皮台词气泡，无需打开大窗口。
     - **桌面快捷喂食**：点击「快捷喂食」直接使用背包食物喂给宠物（若背包为空则流畅打开小屋商店选购），并在宠物处演出**食物图标飞向嘴边 → 开心咀嚼动画 → 飘出 `+XX 饱食度` 浮字**。
     - 保留既有拖拽改位与记忆、自动避让番茄钟与任务操作区、一键收起/展开挂件及仅在「开始工作」页显示的规则。
2. **游戏化「宠物小屋」窗口（温暖绘本 / 动森清新风）**
   - **掌中游戏画框与 HUD**：
     - 采用奶油暖纸底色、柔木/森林绿圆角画框、圆润 3D 轻拟物按压手感按钮，彻底告别后台表单感与原生浏览器 `<progress>` 条。
     - 顶部游戏 HUD 展示拟物**金币胶囊**（余额 + 今日产金）与定制**发光饱食度能量槽**（随饱食度呈现健康绿 / 偏饿琥珀 / 危急脉动红，归零时醒目显示距饿死倒计时牌）。
     - 低频「改名」交互收进宠物昵称旁的小编辑按钮，支持原地轻量修改，不再占用底部主标签位。
   - **上半区「微缩宠物房间舞台（Mini Diorama Stage）」**：
     - 绘制原创矢量微缩房间背景（小窗、柔和光影、地毯/地板景深），并随宠物状态切换氛围（专注暖灯、开心晴朗、偏饿阴天微光、危机警示）。
     - 所有互动在舞台中央实时演出：
       - 直接点击舞台上的宠物可触发摸头撒娇（爱心飘字 + 欢呼跳跃 + 气泡台词）；
       - 喂食时食物飞向宠物嘴边、呈现开心进食表情并飘出饱食度恢复浮字，能量槽平滑涨满；
       - 在商店或衣橱选择装扮时，支持在舞台宠物上**实时试穿预览**（离开试穿自动恢复真实穿搭），正式穿戴瞬间触发**星光闪烁与开心弹跳特效**。
   - **下半区「游戏道具格卡片（Inventory & Shop Grid）」**：
     - 底部精简为清晰图标 + 短文案的 3 个游戏主切换区：**背包喂食 · 道具商店（含食物/服饰分区）· 衣橱换装**。
     - 全部食物与装扮重做为 **2–3 列游戏道具卡片网格**：
       - 每款美食拥有专属原创矢量插画图标（饼干、饭团、便当、热气大餐等）、清晰饱食度增益与库存角标（`×N`）或价格牌（`🪙 价格`）；
       - 每款服饰展示穿戴预览、槽位角标、价格牌及清晰状态徽章（`已拥有` / `穿着中` / 金币差额提示），搭配立体按压手感按钮（买下喂食、存入背包、试穿、购买、穿戴/卸下）。
3. **游戏化领养舞台与饿死星空纪念**
   - **初次领养 / 重新申领**：改为“挑选初始伙伴”聚光灯舞台卡片，切换小企鹅 / 小橘猫 / 小柴犬时对应宠物在台上欢快互动，搭配清爽起名框与游戏主按钮。
   - **饿死纪念卡**：持续饥饿超过 48 小时后呈现温柔的星空小天使纪念舞台，展示曾陪伴天数与「衣橱将完整传承给新伙伴」提示，无缝衔接重新申领。
4. **全面兼容既有核心规则与测试体验**
   - 保持键盘可访问性（`Esc` 关闭、焦点管理、清晰可访问标签）与 `prefers-reduced-motion: reduce` 降级（关闭持续浮动、飞行与粒子动画，保留静态清晰反馈）。
   - 桌面与手机窄屏（`390×844`）下动作轮盘与游戏小屋均自动夹紧在视口安全范围内，不溢出、不挡核心番茄钟控制。

## 明确不做
- 不修改核心经济与生存规则：仍严格保持 `1 分钟 = 1 金币`、`240 金币 = 100 饱食度`、每 24 小时耗尽、48 小时持续饥饿饿死、饿死重领保留衣橱并清空金币与食物背包。
- 不修改后端接口、数据库结构或既有 `account_settings` 宠物存档数据结构（完全兼容已领养用户的旧存档）。
- 不新增宠物音效或引入重型第三方游戏引擎/外部版权素材（坚持轻量化原创 SVG + CSS/React 实现）。
- 不把宠物拓展到「开始工作」之外的其他导航页面。

## 业务规则与异常边界
- **试穿不改存档**：在商店浏览/试穿未购买的衣服时，仅在舞台临时预览效果，不得写入账号存档或改变悬浮宠物实际穿搭；切换标签或关闭小屋后自动恢复真实穿搭。
- **桌面动作轮盘边界**：当宠物被拖拽到屏幕四角或边缘时，环绕动作气泡与迷你状态条必须自动翻转/贴边夹紧在视口内，不得裁切出屏或产生页面横向溢出（`scrollWidth - clientWidth <= 1`）。
- **快速连点与动画叠加**：连续摸头、连续喂食或快速切装扮时，动画与飘字自然刷新/叠加且结束自动清理，不卡顿、不阻塞按钮点击，饱食度满 `100` 时仍禁止浪费喂食。
- **饿死状态隔离**：宠物已饿死时，禁用摸头与快捷喂食，快捷入口与舞台直接引导至星空纪念与重新申领流程。
- **既有存档无缝升级**：已有 `AD-010` 账号存档（品种、昵称、金币、饱食度、背包、衣橱、穿戴、位置、收起状态）在升级后零丢失、直接以新游戏化界面正常呈现。

## 验收标准
1. **桌面活宠与环绕互动**：在「开始工作」页点击已领养的悬浮宠物，先弹出环绕式游戏快捷动作气泡与迷你状态条（而非直接生硬弹出网页列表框）；点击「摸摸」立刻出现宠物开心跳动 + 爱心/台词反馈；背包有食物时点击「快捷喂食」直接在桌面演出进食动画与饱食度提升。
2. **游戏化宠物小屋**：打开「宠物小屋」后呈现温暖绘本/动森风格游戏画框、定制发光饱食度能量条（不再是浏览器原生丑进度条）、上半区微缩宠物房间舞台与下半区 2–3 列原创图标道具格卡片；支持点击舞台宠物摸头、喂食飞入与飘字动画、商店服饰实时试穿预览及穿戴星光反馈；改名通过昵称旁轻入口完成。
3. **领养与纪念仪式感**：初次申领呈现聚光灯选宠舞台；饥饿超过 48 小时后呈现星空纪念卡并顺畅完成重新申领（保留衣橱、清空金币与背包）。
4. **视口安全与兼容**：宠物在四角边缘弹出动作环、打开小屋或在手机窄屏（`390×844`）下均完全位于视口内、无横向溢出且不遮挡番茄钟与任务按钮；`prefers-reduced-motion: reduce` 下关闭粒子与连续动画；刷新与跨账号同步完整保留所有状态。
5. **既有经济与回归全通过**：`1 分钟 = 1 金币`、暂停/休息不产金、24h 耗尽、48h 饿死、衣橱继承与既有番茄钟几何稳定性、快捷完成、移动端布局等回归测试全部通过。

## 必要技术约束与方案
- 宠物视觉与交互组件按职责清晰拆分（如桌面动作环、微缩舞台、道具卡片网格、原创美食/房间 SVG 资源等），严格遵守仓库代码健康审计（TS/TSX 单文件不超 500 行、CSS 不超 1000 行）。
- 同步更新并扩展 `tests/e2e/focus-pet.spec.ts`，在完整保留核心经济/生存/衣橱继承/多账号隔离验证的前提下，覆盖新的环绕互动、摸头、桌面喂食、舞台试穿、游戏化小屋与四角/窄屏边界检查。

## 测试计划
- **静态与单元测试**：执行 `typecheck`、宠物领域与状态单测及仓库健康检查（`audit:health`）。
- **浏览器自动化验证（桌面 + 手机视口）**：
  - 更新并运行 `tests/e2e/focus-pet.spec.ts`：覆盖聚光灯领养 → 悬浮宠物点击弹出环绕快捷动作环 → 摸头互动与对话气泡 → 专注产金 → 商店试穿/购买服饰与穿戴星光 → 美食购买与舞台/桌面喂食动画 → 四角边缘弹出不溢出与拖拽记忆 → 饿死星空纪念与重领保留衣橱 → 跨设备恢复与跨账号隔离，并留存桌面与手机关键状态截图证据。
  - 回归既有专注页计时器几何稳定、快捷完成、每日名言与移动端布局测试。
