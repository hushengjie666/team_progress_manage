# 修复点击宠物漂移并新增快捷道具栏拖拽投喂与换装互动

## 目标与使用场景
目前在「开始工作」页面体验专注宠物时存在两个影响手感的突出问题与体验缺口：
1. **点击宠物随机漂移**：当前点击宠物弹出快捷互动环时，界面会以更大的避障包围盒重新计算宠物位置并强行移动宠物本体，且拖拽起手阈值偏小，导致用户轻点宠物时宠物频繁跳走、漂移到屏幕其他位置。
2. **缺少直观的“拖道具到宠物身上”游戏交互**：目前喂食和穿戴主要靠点文字按钮完成，缺少像 QQ 宠物/桌宠小游戏那样把美食或装扮从快捷道具栏直接拖到宠物身上使用的爽感互动。

本次需求彻底修复点击漂移问题，并在桌面悬浮宠与宠物小屋中引入**快捷食品/道具栏**与**拖拽食物/装扮到宠物身上直接使用**的连贯游戏互动。

## 本次范围
1. **彻底修复点击宠物随机漂移（位置锚定与防误触）**
   - **宠物本体严格原地锚定**：点击悬浮宠物展开或收起快捷互动栏/道具栏/宠物小屋时，**宠物本体坐标绝对不发生位移**；改为由弹出的快捷栏与小屋自身根据宠物当前位置自适应展开方向（上下/左右翻转并夹紧在视口安全区内）。
   - **防轻点误触拖拽**：提高宠物拖拽起手判定阈值（例如从 `5px` 提升至 `8–10px`），仅在明确拖动超过阈值后才进入拖拽态并保存新位置；普通单击、长按未移动或打开/关闭面板均不得触发位置写入或跳动。
   - **稳定避障不乱推**：页面常规交互（按钮状态变化、对话气泡出现、动作栏展开等 DOM 变化）不得把用户已放置好的宠物随意推离原位；仅在初次无保存位置、视口缩放越界或核心位置无法容纳时才执行安全夹紧。
2. **桌面快捷食品与道具栏（Quick Item Dock）**
   - 点击已领养且存活的悬浮宠物时，宠物原地不动，在其身旁自适应展开轻巧的游戏化快捷面板（默认按需展开不常驻遮挡工作区），整合：
     - 极简游戏状态条（饱食度能量槽 + 金币）与「摸摸」「宠物小屋」快捷入口；
     - **快捷食品 / 装扮道具栏**：支持快速切换 **「食品」**（展示背包内现有食物的原创图标、库存角标 `×N` 与 `+XX 饱食度`，空时提供直达食物商店入口）与 **「装扮」**（展示衣橱内已拥有服饰/头饰/配饰图标、槽位与穿着中状态，空时提供直达衣服商店入口）。
   - 道具栏支持在屏幕四角及手机窄屏（`390×844`）自动贴边翻转与夹紧，不裁切出屏、不产生横向滚动条。
3. **拖拽食物 / 装扮到宠物身上直接使用（Drag-to-Pet）**
   - **双场景全支持**：
     - **桌面悬浮宠**：从宠物旁的快捷食品/道具栏按住任意食物或已拥有装扮，直接拖到悬浮宠物本体上松手使用；
     - **宠物小屋内**：在「宠物小屋」中也可直接从下方「背包喂食」食物格或「衣橱换装」服饰格按住道具，直接拖到上方微缩房间舞台里的宠物身上松手使用。
   - **基于 Pointer Events 的高质感拖放演出（兼顾鼠标与触屏）**：
     - **拖起跟手幽灵图标**：按住道具拖动超过起手阈值后，指针位置呈现精致轻浮、微倾斜的道具幽灵图标（`pointer-events: none`，告别浏览器默认半透明丑残影）。
     - **拖至宠物命中区时的即时响应**：
       - 宠物本体亮起柔和的**目标投放光环**；
       - 拖入的是**食物**：若宠物未吃饱，呈现期待进食反应与轻提示（如“啊呜，快喂我！”）；若饱食度已满 `100`，明确提示“饱食度已满，待会儿再吃”并阻止无效投放；
       - 拖入的是**装扮**：在松手前即在宠物身上**实时试穿预览**该件装扮！
     - **松手结算**：
       - 在宠物命中区内松手：食物立即消耗 1 份并触发咀嚼动画 + 爱心/光效 + `+XX 饱食度` 飘字与能量槽涨起；装扮立即穿戴（或已穿着项支持清晰切换/提示）并触发星光闪烁与开心弹跳；
       - 在宠物命中区外松手：安全取消拖拽，不消耗食物、不改动存档，并立刻还原实时试穿预览。
   - **保留点击与键盘无障碍双通道**：用户仍可直接单击道具项或使用键盘完成喂食/穿戴，拖拽与点击操作互不冲突。

## 明确不做
- 不将快捷道具栏改为常驻展开（默认点击宠物展开，保持平时「开始工作」界面清爽；如用户后续希望常驻可再调整）。
- 不支持从「商店」直接把未购买的商品拖到宠物身上扣费购买（仅支持拖拽背包里已有的食物与衣橱里已拥有的装扮；商店继续通过明确的购买与试穿按钮防止误花金币）。
- 不改动核心经济数值（`1 分钟 = 1 金币`、`240 金币 = 100 饱食度`、24h 耗尽、48h 饿死、衣橱继承）、后端 API 或 `account_settings` 存档结构。
- 不新增宠物音效或引入重型第三方拖拽/游戏库。

## 业务规则与异常边界
- **点击零漂移约束**：对位于屏幕任意合法位置（包括右下角、左下角、任务区附近、计时器附近）的悬浮宠物反复点击打开/关闭快捷道具栏、点击摸摸、点击/拖拽喂食与换装后，宠物本体的 `boundingBox`（`x` 与 `y`）变化误差须为 `0`（不超过 `1px`）。
- **饱和与并发防重**：饱食度已满 `100` 时把食物拖到宠物身上松手不得扣减背包库存；请求保存中（`busy`）禁止重复投喂或重复穿戴；网络保存失败时状态与背包数量保持准确不扣错。
- **饿死与收起态隔离**：宠物已饿死时点击直接进入星空纪念/重新申领，不弹出喂食道具栏也不可拖放喂食；收起为迷你挂件态时点击可稳定互动或展开，同样不漂移。
- **拖拽中断安全**：拖拽道具过程中触发 `pointercancel`、窗口失焦或按 `Esc` 时，必须立即清理幽灵图标、关闭目标光环并还原临时试穿状态，不残留悬浮节点。
- **减弱动效与视口安全**：遵循 `prefers-reduced-motion: reduce` 关闭非必要连续/粒子动画；桌面四角与手机窄屏（`390×844`）下快捷栏打开及拖拽过程均不得导致页面出现横向溢出（`scrollWidth - clientWidth <= 1`）。

## 验收标准
1. **点击宠物绝不漂移**：在桌面与手机视口下，无论宠物停在默认位置还是被用户拖到屏幕其他安全区域，连续点击宠物打开/关闭快捷面板、摸摸或打开关闭小屋，宠物本体坐标保持原地不动（`x / y` 偏差 ≤ 1px），绝不再出现随机跳走或漂移；用户主动拖拽宠物仍能顺滑移动并记住位置。
2. **快捷食品与道具栏**：点击存活宠物后在宠物旁自适应弹出快捷面板，能清晰切换查看背包食物与衣橱装扮（带原创图标、库存/穿戴状态与空态去商店引导），面板在屏幕边缘不裁切、不溢出。
3. **拖拽食物到宠物身上投喂**：在桌面快捷道具栏和宠物小屋背包中，按住食物拖到宠物身上时能看到跟手图标、宠物高亮/期待提示，松手后成功消耗 1 份食物、饱食度增加并触发进食反馈；拖到宠物外松手不消耗食物；饱食度满 `100` 时拖入提示已吃饱且不扣食物。
4. **拖拽装扮到宠物身上换装**：在桌面快捷道具栏和宠物小屋衣橱中，按住已拥有装扮拖到宠物身上时实时预览穿搭，松手后成功穿戴并触发星光反馈且宠物外观立即更新；拖到宠物外松手自动还原原穿搭不改存档。
5. **双通道与全回归通过**：点击/键盘快捷喂食与穿戴依然可用；刷新页面与跨账号同步完整保留状态；既有专注页宠物、番茄钟几何稳定性、任务完成动效与移动端布局测试全部通过。

## 必要技术约束与方案
- 拖放逻辑建议抽离为独立可复用 Hook / 模块（基于 Pointer Events + 宠物元素命中框检测），供桌面快捷栏与宠物小屋舞台共用，避免重复代码。
- 严格遵守仓库健康审计（单份 TS/TSX 文件不超过 500 行、单份 CSS 不超过 1000 行）。
- 同步更新与扩展 `tests/e2e/focus-pet.spec.ts` 及相关单元测试，用自动化断言锁死“点击宠物前后坐标零漂移”以及“拖拽食物喂食 / 拖拽装扮换装 / 拖到外部取消 / 满饱食度拒喂”的完整行为。
